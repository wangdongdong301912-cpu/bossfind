# BossFind 岗位雷达模式

岗位雷达模式用于先采集岗位、排序和复盘，再决定是否投递。它不会直接点击 BOSS 的“立即沟通”。

## 数据流

```text
投递策略
-> BOSS 岗位搜索
-> 读取岗位卡片和详情
-> 结构化字段
-> 评分与优先级
-> job_snapshots
-> 前台/移动端列表
```

## 采集字段

- 岗位名称
- 岗位薪资
- 目标城市
- 经验要求
- 学历要求
- 公司名称
- 公司行业
- 公司规模
- 其他福利
- 上下班时间
- 是否双休、大小周或单休
- 职位描述
- 招聘者
- 岗位链接

## 优先级

- S：强匹配，优先进入投递队列
- A：匹配，可投递
- B：可复核
- C：弱匹配
- D：命中排除或明显不合适

## API

```text
POST /api/radar/collect
GET  /api/radar/jobs?limit=120
GET  /api/radar/jobs?priority=S
```
