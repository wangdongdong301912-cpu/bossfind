# 移动端与 GitHub 发布计划

## 移动端路线

当前采用 PWA，而不是立即开发原生 App。

原因：

- 复用现有 FastAPI 和静态前端
- 不引入额外构建系统
- 可直接添加到手机桌面
- 真实投递仍保留在电脑端 Chrome 调试窗口中，安全边界更清楚

移动端主要功能：

- 查看岗位雷达列表
- 按优先级、薪资、城市、福利筛选
- 调整投递策略
- 查看执行记录
- 管理后续投递队列

## GitHub 发布前检查

不得提交：

- `data/*.db`
- `data/chrome-profile/`
- `.env`
- Cookie、验证码、账号密码
- 真实投递记录

建议提交：

- `README.md`
- `.env.example`
- `requirements.txt`
- `docs/`
- `app/`
- `tests/`

## 默认配置

公开版本必须默认：

- 开启演练模式
- 不自动真实投递
- 不绕过验证码
- 不附带任何真实用户数据
